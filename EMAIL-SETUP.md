# Upgrade existing Secret Santa room

1. In the existing Supabase SQL Editor, run the complete `wishlist-upgrade.sql` file. It preserves existing rooms, players and assignments. Copy the moderator access key returned for room 61F69DABC8 and keep it private. If the key has already been generated, the query will return no rows; rotate it securely through the SQL Editor if lost. The key is hashed in the database.
2. Open the updated Pages website. Click Moderator login and enter room code and key. Participants use Resume / edit my registration in their original browser profile to add their email and optional photo. A fresh browser cannot recover an anonymous participant session. Do not share the moderator key.
3. Create a Resend account, verify a sender domain you control, and create an API key. In Supabase Edge Functions, deploy a function named `send-santa-emails` with the source from `supabase/functions/send-santa-emails/index.ts`. Set Edge Function secrets `RESEND_API_KEY` and `SANTA_FROM_EMAIL` (verified sender address). Never add these secrets to GitHub. The function independently validates the caller session and moderator role.
4. Test with a new trial room and two authorized test email addresses before sending to actual participants. Draw privately, then click Send private assignment emails. Each recipient gets one separate email with their assigned person's wishlist and optional picture attachment. The status means provider accepted the message, not necessarily delivered. If sending errors occur, check Resend logs before retries; idempotency keys protect retries only within the provider retention window. For larger rooms send in smaller batches if execution limits are reached.

Existing registration sessions and database rows remain intact. No email is sent until you configure the provider and explicitly click send. The current code has not been tested against the live database or email provider. Wishlists/photos are stored privately in PostgreSQL; no public image bucket is required. Delete the event data after the celebration according to your retention policy.
